Cosmic Advanced Player

A music player that knows the words.

Cosmic Advanced Player plays your local music library with time-synced lyrics, real album art and a desktop that stays in tune. Native on Linux, built with Rust and COSMIC.

Install for Linux Read the source

Free software under the GPL v3. Built for x86_64 and aarch64.

What it does

Point it at your music folders once. It reads every file, keeps the index up to date as you add albums, and stays out of the way while you listen.

Side A, listening

Everything that happens inside the player.

  1. Synced lyricsKaraoke-style lines that follow the song, from .lrc files, embedded tags, LRCLIB or lyrics.ovh. You choose and order the sources.
  2. Real album artCovers embedded in FLAC, MP3, M4A and Ogg files, or the cover.jpg next to them. Each image is cached once.
  3. A library that keeps itself currentFolders are scanned recursively, symbolic links included, and re-indexed when files change. Only new or edited files are read again.
  4. Search as you typeTitles, artists, albums and genres, with partial words and accents ignored.
  5. Gapless playbackLive albums and mixes play without a click between tracks. ReplayGain keeps the volume even.
  6. Pick up where you left offThe queue and position are restored when you open the player again.

Side B, connected

Everything that talks to the rest of your desktop.

  1. Last.fm scrobblingNow playing, scrobbles saved offline until they can be sent, and favourites synced as loved tracks.
  2. Discord Rich PresenceShows “Listening to” with the album cover and a progress bar, over Discord's local connection.
  3. Media keys and panel controlsMPRIS support for keyboard media keys, the COSMIC panel applet, playerctl and phone remotes.
  4. Open anythingPlay a folder or a few files from your file manager or the command line without adding them to the library.
  5. Follows your desktopLight and dark themes, accent colour and fonts come from COSMIC. English and French included.

Install

Every release is built for x86_64 and aarch64, with checksums. Replace VERSION and the architecture with the ones you need.

Debian and Ubuntu

Download the .deb from the latest release, then install it.

sudo apt install ./cosmic-advanced-player_VERSION-1_amd64.deb

Fedora and openSUSE

Download the .rpm from the latest release, then install it.

sudo dnf install ./cosmic-advanced-player-VERSION-1.x86_64.rpm

Any distribution

The AppImage runs without installing anything.

chmod +x cosmic-advanced-player-VERSION-x86_64.AppImage
./cosmic-advanced-player-VERSION-x86_64.AppImage

Try it with Nix

Runs the prebuilt release binary, nothing to compile.

nix run github:Kisakay/CosmicAdvancedPlayer

NixOS and Home Manager

Add the flake, then enable the module. It installs the binary published on GitHub.

# flake.nix
inputs.cosmic-advanced-player.url = "github:Kisakay/CosmicAdvancedPlayer";

# configuration.nix (or home.nix with homeManagerModules.default)
imports = [ inputs.cosmic-advanced-player.nixosModules.default ];
programs.cosmic-advanced-player.enable = true;
